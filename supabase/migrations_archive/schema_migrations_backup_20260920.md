# Sikkerhedskopi: produktionens migrationsbogføring før sammenlægningen

150 rækker i `supabase_migrations.schema_migrations` blev erstattet af én række
for baseline (`00000000000000`).

der er kørt. Hverken data eller struktur blev ændret af udskiftningen.
